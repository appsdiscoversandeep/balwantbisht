POLITIAN STATIC HTML PACKAGE

Files:
- index.html: cleaned static homepage markup
- css/style.css: local theme stylesheet entry point and custom overrides
- js/main.js: static navigation enhancements
- assets/: local theme dependencies, fonts, and images copied from the supplied archive

Run by opening index.html or serving this folder with Apache/Nginx.

WordPress admin/API scripts have been removed. Donation, contact form, shop, and newsletter submissions need a backend or third-party service.
